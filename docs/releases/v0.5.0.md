# Release notes — v0.5.0 (2026-08-27)

Six additional strategies on top of v0.4.0. Fills the family gaps left by FEAT-001..004.

## What's new

| Module | Family | Signal |
|--------|--------|--------|
| `src/bollinger.py` | Single-stock mean reversion | close < SMA20 - 2σ, SMA200 trend filter |
| `src/rsi2.py` | Short-horizon mean reversion | RSI(2) < 5, exit on close > 5d SMA |
| `src/dual_momentum.py` | Combined momentum | 12M absolute gate + relative cross-section rank (Antonacci) |
| `src/magic_formula.py` | Value + quality rank | EY+ROE composite z-score (price-proxied — see ADR-005) |
| `src/risk_parity.py` | Allocation | Inverse-vol weighting, monthly selection, daily rebalance |
| `src/dividend_carry.py` | Yield / carry | Top quartile by static yield map, monthly rebalance |

**Total now: 12 strategy families across 5 FEATs, 44 tests pass.**

## How to run

See [`docs/runbooks/strategies.md`](../runbooks/strategies.md) for one-liners per module.

```bash
pip install -r requirements.txt
python3 -m pytest tests -q           # 44 tests
```

## Honest caveats (delta from v0.4.0)

- **Magic formula uses price-derived proxies** for EBIT/EV (EBIT not in yfinance). Rank structure preserved; absolute level biased toward momentum. See ADR-005.
- **Dividend yield is a static map** (`src/dividend_carry.py:YIELDS`), last refreshed 2026-08. Dividend cuts not detected. Refresh manually when stale.
- **Risk parity's daily rebalance** assumes 1bps cost — real Indian costs (brokerage + STT + impact) will reduce returns. Validate on real data before trusting the curve.
- **All six are in-sample.** Real validation requires walk-forward + regime tests (v1.0.0 scope).

## What's still NOT shipping

Same list as v0.4.0 plus:
- Options-based strategies (full VRP, iron condor, cash-secured put) — need chain data, listed in ADR-005.
- Event-driven with real announcements (M&A arb, insider buying, earnings drift) — need event data source.
- Intraday / overnight strategies — need intraday bars.
- Real fundamentals-based strategies (Piotroski, real Greenblatt) — need annual report parser.

**Estimated ~15 named strategies not in v0.5.0.** Full list in ADR-005.

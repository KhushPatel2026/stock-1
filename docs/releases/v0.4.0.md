# Release notes — v0.4.0 (2026-08-27)

First tagged release of the stock-1 Nifty 50 systematic strategy suite.

## What's shipping

Four independent strategy suites, each with its own backtest engine, metrics, and tests. They share the same data layer (`src/data.py`) and universe (`src/universe.py`) so a single yfinance fetch serves all of them.

| FEAT | Suite | Style | Cost model | Tests |
|------|-------|-------|-----------|-------|
| FEAT-001 | Trend-following + vol-adjusted risk | Long-only | None (post-MVP) | 16 |
| FEAT-002 | Stat-arb / pairs trading | Market-neutral | Indian (brokerage + STT + slippage) | 7 |
| FEAT-003 | Institutional: factors / options vol / events / risk overlay / walk-forward | Multi-strategy | Per-module | 7 |
| FEAT-004 | Advanced quant: gap-fade / sector-neutral / microstructure / beta-hedge / ML overlay | Multi-strategy | Inherits | 8 |

**Total:** 38 tests pass, coverage 82% on core modules (88-99%).

## How to run

See [`docs/runbooks/strategies.md`](../runbooks/strategies.md).

One-liner smoke test:
```bash
pip install -r requirements.txt
python3 -m pytest tests -q
```

## What's NOT shipping (and why it's OK)

- **Live trading adapter** — research-only. No broker integration yet.
- **Dashboard** — backtest output is CLI; no web UI.
- **Multi-timeframe** — daily bars only.
- **FEAT-001 transaction costs** — flagged in honest caveat; FEAT-002 already models Indian costs.
- **Walk-forward + regime tests (2018/2020/2022)** — milestone target for v1.0.0.

## Honest caveat

Backtests are in-sample and on Nifty50 large-caps. Real edges need walk-forward, regime stress, and out-of-sample paper trading before any live capital. Treat v0.4.0 as research scaffolding, not a production strategy.
